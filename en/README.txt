Quiet Path 英語版

使い方
ZIPを展開し、index.htmlをブラウザで開いてください。
FlowとDiscoverは各20問です。

GitHub Pagesで公開する場合
既存のquiet-pathリポジトリ内に en フォルダを作成し、
このフォルダの index.html / flow.html / discover.html を配置します。
公開後の英語版URLは https://career-analysis-lab.github.io/quiet-path/en/ です。
日本語版トップに英語版へのリンクを追加すると切り替えられます。
現在の日本語版ファイルを置き換える必要はありません。

内容
トップ、ルール、操作、問題名、ヒント、進行表示、成長演出、
エンディング案内、Flowの感想フォームを英語化しました。
日本語版へのリンクがあります。
問題・配色・画像・進捗保存の仕組みは公開版を引き継いでいます。
同じブラウザ・公開元では既存の進行データを共有します。
感想フォームの選択肢の内部コードは既存集計との互換性のため維持しています。
英語回答にはlanguage=enを追加しますが、既存の受信側で保存されるかは未確認です。
トップのGA4 game_selectedイベントにlanguage=enを追加しています。

確認済み
JavaScript構文。全40問の解答経路とクリア判定。
ヒント、一手戻す、次の問題、やり直し、完成形表示がクリアに加算されないこと。
表示文中の翻訳漏れ（日本語切替リンクと内部回答コードを除く）。

未確認
スマートフォン/iPadでの実際の表示・タッチ操作。
既存Google Apps Scriptへの実送信と受信。
公開サイトへのアップロードは行っていません。
